## User Workflows (Quick Reference)

Quick-access for common workflows — use these before loading a full doc:

**Start a project**
1. Click "New Project" or tell the concierge what you want to work on
2. Give it a name and a one-line vision
3. Optionally click "Set up with AI" — an agent will structure it for you

**Create and run a task**
1. Navigate into a project → click "Add Task"
2. Give it a clear, specific title and description
3. Click "Spawn Agent" — the agent reads the task and proposes a plan
4. Review the plan in the notification panel → Approve or suggest changes
5. The agent executes → checks its own work → marks it done

**Check what agents are doing**
- Session panel (left sidebar) — status dots: green = working, yellow = waiting for you, grey = idle
- Click any session to open its chat and see live output

**Respond to an agent waiting for you**
1. Look for a yellow dot in the session panel, or a badge on the notification panel (right side)
2. Click the notification → read what the agent is asking → reply

**Find something**
- Press Cmd+K (Mac) or Ctrl+K (Windows/Linux) to open global search
- Type a task name, file name, or topic — results appear instantly
- Use the "AI Search" option to describe what you're looking for in natural language

**Give feedback**
- Click the 💬 button (bottom-left) — that's this Helper Bot
- Or tell an agent directly in the chat
