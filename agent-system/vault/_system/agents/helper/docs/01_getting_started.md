# Getting Started

## What Is This?

This is your personal AI workspace — a place where AI agents help you get work done. You describe what you want, agents plan and execute it, and you stay in control throughout.

Think of it like having a team of capable AI assistants who are always available, remember everything you've worked on together, and can handle complex, multi-step tasks while you focus on the things that need your judgment.

---

## The Dashboard at a Glance

When you open the dashboard, you'll see:

```
┌─────────────────────────────────────────────────────┐
│  Session Panel (left) │   Main Area   │ Notif (right)│
│                       │               │              │
│  ● concierge          │  Home Screen  │  [Approval   │
│  ○ task_research      │  or PM View   │   items here]│
│  ○ task_writing       │  or Chat View │              │
│                       │               │              │
│  [💬 Helper Bot]      │               │              │
└─────────────────────────────────────────────────────┘
```

**Session Panel (left sidebar)** — Your active AI conversations. Each dot is a running agent. Green = working, yellow = waiting for you, grey = idle.

**Main Area (center)** — Switches between views:
- **Home** — Your dashboard with status widgets
- **Project Manager** — All your projects, tasks, and goals as cards
- **Chat** — Live conversation with the agent you've selected

**Notification Panel (right sidebar)** — When an agent needs your input, it shows up here. Check this regularly.

**Helper Bot (bottom-left 💬)** — That's this. Ask anything, or report issues.

## Your First 5 Minutes

### Step 1: Start a session

Click **"New Session"** or **"Start Concierge"** in the session panel. A concierge agent will start up and greet you.

The concierge is your main point of contact. Tell it what you want to work on:
> "I want to start a research project on multi-agent AI systems"
> "Help me organize my thesis work"
> "Create a project for building a web app"

### Step 2: The concierge sets things up

The concierge will create the project, structure it, and ask if you want to start working. It may suggest some initial tasks.

### Step 3: Spawn your first agent

Once you have a task, click **"Spawn Agent"** (or "Set up with AI"). An agent will appear in the chat panel and start reading your task.

### Step 4: Approve the plan

The agent will propose a plan — a numbered list of steps it intends to follow. A notification will appear in the right panel: **"Review plan for [task name]"**.

Click it → read the plan → click **Approve** (or type a response if you want changes).

### Step 5: Watch it work

After approval, the agent starts executing. You can watch it in the chat panel. When it's done, the task is marked complete and you can review the output.

## Navigating the Dashboard

| What you want | How to get there |
|---------------|-----------------|
| Project overview | Click the PM icon or press the project name in the session panel |
| Switch to chat | Click any session in the left panel |
| Go back | Press **Escape** or **Backspace** in the PM view |
| Search everything | **Cmd+K** (Mac) or **Ctrl+K** (Windows/Linux) |
| Open home screen | Click the home icon or the dashboard logo |
| See notifications | Look at the right panel, or the badge on the bell icon |

## What to Expect

**Agents are thoughtful, not instant.** They read your task, think about it, and propose a plan before doing anything. A simple task might take 30 seconds to plan; a complex research task might take a few minutes to execute.

**You're always in control.** Nothing major happens without your approval. If an agent proposes something you don't like, reject it and explain what you want instead.

**Agents remember context.** They read your project history, past sessions, and related tasks before starting. You don't need to re-explain everything every time.
