# Home Screen & Widgets

## The Home Screen

The home screen is your at-a-glance dashboard. It shows status widgets that give you an overview of what's happening across all your projects.

Navigate there by clicking the **home icon** in the top bar or the dashboard logo.

---

## Built-in Widgets

### Agents Widget

Shows all your active AI agent sessions:

- **Working** — agents currently executing tasks (green dot)
- **Waiting** — agents that need your input (yellow dot)
- **Idle** — agents that have finished or are between tasks (grey dot)

Click the widget to expand it and see details for each agent:
- Which task it's working on
- How long it's been running
- Its current status message

Click any agent row to jump to that session's chat.

### Goals Widget

Shows progress toward your goals across all projects:

- Each goal shows a progress bar based on how many linked tasks are complete
- Target date is shown — turns red if you're behind
- Click to expand and see individual milestones

---

## Widget Modes

Each widget card has two modes:

- **Compact** — a small summary card. Shows the key numbers at a glance.
- **Expanded** — click the card to see full detail: list of all items, statuses, links.

Click the card header to toggle between modes. Some widgets can also be configured to start in expanded mode.

---

## Customizing Your Home Screen

**Reorder widgets:** Drag a widget card to move it. Drop it in the new position.

**Show/hide widgets:** Click the **widget menu** (usually a gear icon or "+ Add Widget" button) to toggle which widgets appear.

**Custom widgets:** Agents can build entirely new widgets for you. Ask an agent:
- "Create a widget that shows my paper reading queue"
- "Build a home screen card for tracking my weekly writing goals"
- "Make a widget that summarizes what tasks I completed this week"

The new widget will appear on your home screen and update automatically.

---

## Tips

- Check the home screen at the start of each work session — the Agents widget will show you if anything is waiting for your input.
- If the Goals widget shows a goal is behind schedule, click it to see which tasks are blocking progress.
- You can have multiple home screens for different contexts — ask an agent to set one up.
