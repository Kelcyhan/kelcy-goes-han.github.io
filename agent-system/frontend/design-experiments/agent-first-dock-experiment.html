Design intent

左侧负责快速进入 chat/agent；右侧围绕当前卡片对象给出 brief、证据、活动和 agent 操作。

IA rule

Expanded rail 是全局会话入口；Object Card 是局部工作单元。右侧只显示“这个对象上的 agent 状态”。

Open question

左侧默认展示 Active，还是根据用户上次模式记忆？我的建议是新用户默认 Active，成熟用户记忆上次选择。

Reference

Linear / Jira / ClickUp 都把结构对象作为稳定骨架；GitHub agent 模式则把 delegation 和 review 做成异步工作流。

Local artifact
