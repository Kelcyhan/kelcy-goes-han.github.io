# Locusly Brand Direction

## Recommendation

Use **Locusly** with the domain **locusly.ai**.

I checked the domain on June 23, 2026 with WHOIS. The `.ai` registry response returned `Domain not found.` for `locusly.ai`, and exact-name web searches for `locusly.ai` / `Locusly` did not surface an obvious active product using the name. Domain availability can change quickly, so buy it before announcing the brand.

## Why This Name

`Locusly` comes from **locus**: a place, center, or point of attention. That maps tightly to the paper's core argument:

- The product is not just an AI chat interface.
- The workspace is the shared state.
- Papers, notes, code, data, drafts, images, receipts, and briefings stay colocated.
- Humans and agents work through the same artifacts.
- The user's job shifts from rebuilding context to directing attention.

The name feels calmer and more workspace-native than the old direction. Compared with `ctxnest.ai`, it is easier to say and more brandable.

## Positioning

**One-line:** One shared locus for human and agent work.

**Tagline:** All in one, shared in context.

**Longer description:** Locusly keeps research artifacts, AI sessions, and project continuity in one living workspace, so people and agents can work from the same context over time.

## Brand Principles

1. **Artifact-first**: Show papers, notes, code, data, drafts, and decisions as the core object.
2. **Shared state, not memory magic**: Emphasize ordinary files, addressable artifacts, receipts, and briefings.
3. **Human attention stays central**: The agent system should feel powerful, but the researcher is still steering.
4. **Quiet confidence**: No glowing brain, sci-fi oracle, or generic neural network visual language.

## Visual System

The logo mark is built from the name itself: a bold **L** becomes a shared coordinate path, and the bend of the L becomes the **locus** - the point where human work, agent work, and artifacts meet. The small panels and orbit lines reference shared context without turning the mark into a generic network diagram.

This gives Locusly a clearer IP hook:

- **L**: the first letter and the visible memory shape.
- **Locus point**: the context center.
- **Orbiting artifacts**: papers, notes, code, drafts, and agent outputs staying in one field.
- **System fit**: dark glass surface, fine grid, compact shapes, and existing product accent colors.
