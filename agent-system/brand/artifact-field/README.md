# Artifact Field

## Why This Solves The Naming Problem

**Artifact Field** is not as generic as `Locus`, and not as strange as coined Greek-style names. It is a practical working brand:

- `Artifact` names the product's real object: papers, notes, code, drafts, data, images, receipts, briefings, and agent outputs.
- `Field` suggests a shared surface / operating field where those artifacts stay related over time.
- The name explains the paper's core idea without requiring a footnote: artifact colocation creates shared context.

## Logo Idea

The mark is a field of artifact tiles converging into a shared context point:

- Four outer tiles: heterogeneous artifacts.
- Center tile: the current shared context.
- Subtle grid: ordinary filesystem / workspace structure.
- Blue, cyan, and orange: system-native colors for active work, shared state, and review.
